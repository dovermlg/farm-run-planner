# Changelog

## 1.15.0 — pending release

- Add a saved backpack and equipment editor inside the plugin tab, with Capture and Save setup buttons.
- Link captured setups to RuneLite's Bank Tags layout and filtering. Keep calculated requirements available for comparison.
- Include configured teleport supplies in requirements and inventory planning, with tablets as the default.
- Put the packing checklist behind an eye button, collapsed by default.
- Add movable on-screen directions that appear after Start run and disappear when stopped or completed.
- Change the same button to Stop run while active. Stopping keeps completion marks and clears directions, step borders, teleport outlines and the linked bank view.
- Skip hardwoods still estimated to be growing when preparing the next run, while keeping them selected in the preset.
- Use Farming Guild as the default resupply bank and follow the preset's Guild travel choice. Switch existing Grand Exchange presets once; preserve other bank choices.
- Include captured setups in version 7 local preset backups while retaining support for earlier formats.
- Use the spade-and-sprout icon in the sidebar and Plugin Hub listing.
- Improve item matching, stale-data handling and bank-view cleanup. Add ignore rules for local credentials and profile files.

All game actions remain manual. No backend, telemetry or external Inventory Setups dependency is added.

## 1.14.4

- Enable the plugin by default when installed, following Plugin Hub review feedback.
